## 📕 **v2.3.0-beta.1 （公测版 v1） 更新内容**

### 🔄 **鸢报四合一**

适配新版鸢报，会按顺序循环执行四种鸢报。

### 🏯 **据点相关**

- 新增「记录奖励内容及数量」选项：支持记录洛阳、寿春派遣及月卡情报扫荡奖励，并可选自动同步奖励详情至 **鸢鸢相抱 YuanHub - 库存追踪**。使用前建议先通过百宝箱识别背包并同步初始库存。
- 修复快速扫荡无情报时的退出及后续任务衔接，增加未消耗行囊提醒。

### 🗡 **地宫助手**

- 调整扫荡按钮点击区域，修复部分情况下没有点中扫荡的问题。

### 🔄 **6-24/7-15 刷到体力耗尽** / 🔢 **6-24/7-15 指定循环次数**

- 补充主线入口识别模板，修复新 OCR 模型下无法识别北地主线入口的问题。

### 🔄 **自动刷神秘洞窟**

- 调整洞窟重开时「前往」按钮的识别，改善连续刷取时的流程衔接。

### ✨ **自动抄作业V3**

- 新增重开记录，在 MaaYuan 根目录的 `copilot_restart_report.txt` 中记录时间、回合、重开原因及累计次数，并保留各次任务的历史汇总。

### 🧯 **红点消除助手**

- 调整密探传闻收集度奖励的点击位置，修复领奖时卡住的问题。

### 👆 **百宝箱**

- 新增「自动识别背包」
  - 自动统计背包道具与心纸数量，保存本地报告，可选同步至 **鸢鸢相抱 YuanHub - 库存追踪**，也可选择不识别心纸。

- 新增「采集密探信息」
  - 从当前密探开始向右采集密探属性、奇闻属性、化极节点及命盘信息，保存为本地 JSON 文件，可选自动同步至 **鸢鸢相抱 YuanHub - 密探名册**。
  - 支持选择游戏版本、仅扫描一位，以及仅更新养成中的密探。按养成状态筛选时，需开启同步并填写具有密探读取权限的连接码。

- 新增「星石背包自动采集」
  - 从「星石背包 → 主星 → 顶部」启动，自动采集主星、辅星与经验星曜，组装为完整批次，可选同步至 YuanHub。

- 新增「使用兑换码」
  - 支持输入兑换码并自动兑换，增加输入前的页面容错。**仅限如鸢，兑换后需自行前往邮箱领取奖励。**

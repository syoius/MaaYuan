自动战斗作业 ​

提示

需确保已导入作业且按作业需求调整队伍及命盘，并在正确的页面点击“开始任务”。

v2.0.0-beta.3及以上版本新增“自动编队”及“命盘检查”功能（测试中，可能有bug，欢迎反馈）。

作业运行 ​

导入作业 ​

  • 本地导入：下载JSON文件后，在MaaYuan中选择"本地导入"，选择下载的文件即可；也可直接下载至 resource\copilot-cache（Maa作业文件夹），刷新后生效（勿放原copilot文件夹，避免资源加载失败）。
  • 神秘代码导入：从作业站复制代码后，在MaaYuan自动战斗界面粘贴并选择对应导入方式：
  • 单份作业：左键"使用神秘代码”；
  • 作业集：右键"使用神秘代码"（支持批量导入作业集中的所有作业）。 导入成功后，作业会出现在列表，可快捷切换。作业需要点击激活后才能使用，若显示"未激活"，需点击对应作业加载。

运行作业 ​

  • 自动抄作业任务

    • 未勾选【战斗中开始抄作业】：在编队界面开始任务，即页面有"开始战斗"处；
    • 勾选【战斗中开始抄作业】：进入战斗后开始任务，即右上角有"回合X"处。
    • 记得展开游戏内自动/手动X倍速面板。

  • 特殊适配任务

    • 部分任务（如刷成就、洞窟等）会自动循环。
    • 若作业设置"点左上角重开"，则支持自动导航下一把，目前支持主线、洞窟、兰台、地宫遗迹。
    • 洞窟作业需在洞窟进门处运行（需切回原界面选"自动刷神秘洞窟任务"）。
    • 非专项页面开始任务，只要切到抄作业专项页面（含神秘代码导入/作业列表等），均按上述规则操作。

作业录制 ​

v2.0.0-beta.3 及以上版本支持录制作业：

  1. 进入录制作业界面。
  2. 点击“开始录制”。
  3. 使用“操作记录仪”悬浮窗记录动作。
  4. 如果模拟器连接正确，操作会同步到模拟器中。

配套网站介绍 ​

基础操作 ​

  • 注册登录：使用者可不注册，制作者需注册（必填：邮箱、用户名、密码）。
  • 查找作业：通过搜索栏按标题/描述/神秘代码筛选，或按关卡分类查找。
  • 下载作业：点击作业右上角「复制神秘代码」（直接粘贴至MaaYuan快速使用），或下载JSON文件；作业集支持批量复制导入。
  • 作业集管理：支持创建公开/私有作业集，可将常用作业加入集合，便于快速浏览及加载至MaaYuan。

作业制作 ​

当前作业站支持「自由编写」及四种方式导入。

  • 进入编辑：点击工具栏「作业编辑器」进入页面。
  • 填写基础信息：包括关卡、标题（建议含具体关卡信息，如“白鹄11月245星”）、描述、作业来源（搬运需标注原作者及链接）。
  • 司命设置：可统一设置延迟（默认“普通”，可选“极速/超慢”），支持单独调整普攻/大招/下拉等待时间（如大招动画长则增加对应时间）。
  • 可见范围：测试期可选“仅自己可见”（仍可通过神秘代码分享），确认后自主选择是否公开，鼓励公开优质作业。
  • 视图切换：支持「动作链」（原司命视图，数字为站位）、「类表格」（通用视图，数字为出手顺序）。
  • 额外操作：添加等待、切换目标、开启自动战斗、关卡内互动（当前支持主线关卡局内工具箱）。
  • 重开条件：支持全灭重开、左上角重开、无橙星/紫星/蓝星重开、密探阵亡检测重开。
  • 修改本人作业：点击右上角用户名→个人主页→选择作业→点击「管理」。
  • 修改他人作业：进入作业页→点击右上角「复制到编辑器」自由修改，或在「作业编辑器」→导入→「神秘代码导入」或「导入本地文件」。
  • 导入作业：
    1. 导入本地文件：可导入JOSN文件，对于使用MaaYuan录制的文件，可导入后进行进一步修改，如添加延时、重开等操作。
    2. 导入AutoFightGen表格：可导入EXCEL文件，需保证表格为5列。每个单元格的格式为：数字 + 动作，如1A、2↑、3↓等，数字表示出手顺序。多个动作可连续写，例如 1A6A。对于需要切换敌人的表格，可使用单元格的背景颜色表示攻击目标位置，导入作业站后需要选择不同颜色对应的敌人位置。

      示例：

      1A2↑3A4↓5A
      4↑10↓1↑7↑3A8↓2↑6A5↑9↑
    3. 导入神秘代码：使用作业站复制得到的神秘代码进行导入操作。
    4. 辟雍导入(粘贴JSON)：在辟雍学府生成的作业表格支持直接导入作业站。

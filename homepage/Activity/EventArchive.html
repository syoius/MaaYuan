往期任务任务 ​

TIP

本文仅存档往期任务&活动版本信息。

去去指哀牢 ​

版本：v2.1.2-Beta2及以上

自动导航、自动清体力，四种辅助模式，兼容 推剧情➡️刷家具➡️卡1心神刷代币 及 0心神无限刷成就。

  • 刷家具➡️卡1心神： 把体力消耗到个位数（推剧情/扫荡，etc.）后再使用，可选家具刷齐后是否继续刷登山杖；
  • 推剧情➡️刷家具➡️卡1心神刷代币及0心神无限刷： 测试中，暂无适配21层之后的，可能卡随机对话/困难关或者其他鸟的小巧思，建议人工监察，可选家具刷齐后是否继续刷登山杖；
  • 卡1心神： 适合已经关卡全通+家具全收集的选手。由于中后期关卡有2波怪，所以会直接导航到第8关进行战斗；
  • 无限刷（成就） 适合无视心力反复刷关做密探成就。由于中后期关卡有2波怪，所以会直接导航到第8关进行战斗，可选【游戏内置自动战斗】&【抄作业】需要先在侧边栏的【自动作业】加载/激活好要用的作业。

夜以继日的绩效评估/披荆斩棘的实习考核 ​

版本：v2.1.2-Beta1及以上

支持自动答题、扫荡、自动完成六属性战斗任务。 请确保完成前置任务（25次鸢报、消耗五铢钱60w、送礼30次、消耗白金币200、消耗家具派遣体力100、打造5家具、合成30次材料、6种属性的战斗、消耗15行囊）后再开始执行本任务！否则未完成的任务会被直接跳过/结束当前任务。 如启用自动完成六属性战斗任务请【保证编队的前2位成员能够速刷6-24】并【预留20体力】，启用本功能时会在清活动任务之前自动替换不同属性的队员刷2次6-24。

魂生又一串 ​

版本：v2.1.1-Beta7

支持自动进入活动、选择男主店铺、选择遇到踢馆/评选赛是否继续、开始营业与结业流程。 【烧烤模式】：纯挂机 / 自助烤串。自助烤串支持分别设置【菜单（食材/饮品）】与【烧烤时长】等参数。

  • 【烧烤店铺选择】：由于会切换到对应男主店铺，注意在对应男主店铺选好菜再开始任务，否则会进入失败；
  • 【自动选菜】：进入烧烤前的选菜，可能因文字识别等原因出现问题，可以第一次让麻圆选菜后取消勾选；
  • 踢馆模式说明： 【无脑挂机】直接点开始踢馆并等待失败，继续烤串； 【手动踢馆后继续】输出日志等待手动踢馆，踢馆完成后继续烤串； 【直接结束任务】遇到踢馆直接停止整个MaaYuan任务；
  • 评选赛是否继续： 【继续】：放弃报名，继续挂机烤串（适用于长时间挂机）； 【不继续】：直接结束MaaYuan任务，适用于后期刷评选赛奖杯；

咪教模拟器 ​

版本：v2.1.1-Beta1

  • 【挂机清体力】 自动导航+自动选人+自动过剧情进入龙女/粮草线挂机，直到体力耗尽
  • 【实时辅助模式】会自动收取已完成任务+处理特别行动，并点掉各种弹窗。任务派遣需要配合派遣方案推荐器手动处理。
  • 由于每个人的电脑性能和模拟器延迟不同，射箭和黄条不敢保证百分百靠谱，也可以关闭对应的辅助功能。

花灯绘 ​

版本：v2.1.0-Beta2

  • 每日任务：完成花灯绘每日任务（悬挂花灯 + 赠送贴纸），不拆红包。
  • 自动拆红包：自动拆锦包囊内拥有的红包。
  • 支持“十全大红包”开关。

躬耕南阳 ​

版本：v2.0.0-beta3

  • 点击“躬耕南阳 V1”齿轮，选择需要 Maa 鸢执行的内容。

邪修存钱篇（仅放置柏木，无水无灯） ​

  • 11级之前请点击Maa辅助收菌子，之后建议关闭此选项；
  • 可以设置开启【自动补充营养液】及【自动购买营养液】
  • 如果开启了【自动购买营养液】，那么Maa鸢会自动卖掉邪修法收获的4种菌子作为本金，并且你需要拥有【450蘑菇力】或【9瓶营养液】作为起始资本。
  • 最后也是建议大家一定要做的，就是使用前先手动把【普通老土草帽菌】、【常见实习泡泡菌】、【未能长大的草帽菌】和【未能长大的泡泡菌】都卖掉，这样新收获的菇都会在回收列表最底下，能够节省每次回收时翻找列表花费的时间，也避免翻列表时模拟器过于卡顿导致意外。

点击开始任务，让Maa鸢来帮你养菌子吧。

宇宙探索篇 ​

识别顺序调整，新增【攻击珍品灯油/保湿水星球】选项并补充提示。

天下隐光 ​

版本：v1.0.1-beta.3

  • 自动根据进度处理体力（首通/爬塔/扫荡等）

  • 主理人还卡在第十二层，不确定第五章能不能用

望祈丰年 ​

版本：v1.0.1-beta.1

  • 一键小助手，支持自动导航，自动答题，自动领取奖励。

朝歌之战 ​

版本：v0.9.13-beta.9

  • 本功能只是囤资源小助手，暂不支持推主线。
  • 支持囤粮 / 爬塔。
  • 支持自动处理叹号 / 自动迎战。
  • 支持选择刷突破材料（低级 / 高级 / 都不刷）。
  • 需要挂几回合，就把重复次数设为几。
  • 运行后会按照“叹号事件 → 资源战斗 → 突破素材战斗”的顺序消耗行动力，并自动推进回台。
  • 建议把界面右上、右下的面板都收起来。
  • 已配备自动导航，将强制开启游戏内置自动战斗。
  • 如果想节约时间，可以不设置选项里的“自动补兵”和“指定队伍”。
  • 附：会开自动过所有主线战斗的 56 回合流程攻略&进度追踪网页

月海夜航船扫荡 ​

版本：v0.9.13-beta.8

  • 支持永夜后扫荡小怪，可自选队伍。

邺城之战 ​

版本：v0.9.13-beta.6

  • 支持自动导航，也可在进行中的攻取关卡内启动，会自动接管当前进度继续刷。
  • beta7 适配“三棱镞已满”的弹窗。
  • 支持全部关卡、全部战车选择。
  • Maa 会强制开启自动战斗，请提前准备好编队；想刷藏兵洞的，也需要提前选好首发队员。
  • 支持升级天赋树（不升级 / 升攻击 / 升生命），支持收集壮行酒。
  • 支持自动购物，金 / 紫 / 蓝 buff 识别精度可调。
  • 支持路径优先级选择（刷煤 / 收集 buff）。
  • 走不动路时，可在“任务设置 - 高级”中调整识别精度（0~1 之间的实数）。
  • 如识别不到应去的高亮节点，可把对应节点的识别精度调低；如一直在点灰色节点，可把对应节点的识别精度调高。
  • 循环刷图建议配置（参考云梦）：设置好后请关闭代号鸢再启动任务。
  • 注：新版 MuMu 需要先创建单个模拟器的桌面快捷方式。

爱乐之村 ​

版本：v0.9.13-beta.5

  • 本活动想要收益最大化需要合理运用指定骰子；Maa 不动用此类高价值资源，因此无法保证收益率。
  • PK：只在数值不够且炸工坊时使用泻药。
  • 公务：自动处理，支持指定办公倾向（贤明 / 混沌）。
  • 购物：自由设定是否买泻药及刷新商店。
  • 码头：自动选择当前最低属性为目的地。
  • 赌场：自由选择对赌设定。
  • Tip：高级选项卡中支持调整骰子识别精度。

魂生一串 ​

版本：v0.9.13-beta.3

支持自动导航，适配五种食材，支持自动丢掉烤焦的食物、自动升级食堂（可选）、自动接管继续营业。

不支持打蟑螂，建议手动补刀。

回滚弹窗已适配。

华堂夜宴 ​

版本：v0.9.13-beta.1

  • 支持自动首通及扫荡故事，自动领取奖励、每日免费体力以及进行逐猎扫荡。
  • 可选项【直接进行逐猎扫荡】（只清射决不清膏腴）/【清膏腴后进行猎逐扫荡】、【清膏腴后领取奖励】、【猎逐遇到未通关敌人直接结算】

江东万里船 ​

版本：v0.9.9

启动后会自动导航进入活动界面，也可在未完成水战关卡内启动，会自动接管当前进度继续刷。

Maa会强制开启自动战斗，请提前准备好编队。

常规设置包括：关卡选择、游船选择、路径优先级（刷材料/集buff/通关）、船歌优先级、是否进行漂流罐及迷雾战斗、是否自动购物、延时设置、超时后行为（关闭游戏/重开关卡）、战斗失败后行为（停止任务/重开关卡）、战斗超时时间。

高级设置包括：各级精度自定义。识别不到某个节点，就把对应的识别精度改低点；一直点灰色的节点，就把对应的该灰色内容识别精度改高点。

披荆斩棘的实习考核 ​

版本：v0.9.7

  • 支持自动导航。自动完成考核任务，会从最后一位密探往前完成任务。支持【自动刷新任务】及【指定战斗队伍】。
    • 知识问答 - 根据社区维护的问题集自动选择正确答案。可能会因识别不准而提示答题失败，此时会停在答题界面，请手动选择答案后再重新开始任务。繁中版目前很难识别内容是数字的选项。
    • 奇袭/密探考核/密探特训 - 只扫荡，无法扫荡则会跳过。
    • 神秘事件 - 自动走格子、自动战斗（使用指定的队伍）。
  • 如开启【自动刷新】功能，请确保完成前置任务（25次鸢报、消耗五铢钱60w、送礼30次、消耗白金币200、消耗家具派遣体力100、打造5家具、合成30次材料、6种属性的战斗、消耗15行囊）后再开始执行本任务！否则未完成的任务会被直接跳过。

温泉山庄小管家 ​

版本：v0.9.4.2

已配置自动导航，同时勾选时张修和钓鱼时，会先刷张修到没有斗志后再去钓鱼。

  • 自动刷张修（可选 是否使用秋芥酱补充体力）
  • 自动钓鱼（可选钓竿、助力密探、当前钓竿耗尽后是否 自动切换至低级钓竿 继续钓鱼）

云梦巫乡挖煤 ​

版本：v0.9.0

  • 解放双手的挖煤工具，目前推出四个版本以供选择；除当前版本外，往期版本可在新任务添加。
  • 参考资料附有“模拟器路径设置”与“专心挖煤模板示例”说明。
  • 当前版本 V4：默认无限次数，可选层数（入云梦、龙虎一 / 二、镜境一 / 二 / 三 / 四、载道岩洞、替天山窟），可选自定义延迟，可选识别精度，并带超时检测（5-15 分钟）；版本 v0.9.3。
  • 启动后会自动导航进入活动界面，也可在未完成的巫竞关卡内启动，会自动接管当前进度继续刷。
  • V4 针对 MuMu 可能卡死的问题在各环节加入了超时检测：5 分钟无动作会尝试关闭游戏后中止任务。
  • 点任务列表右上的 ➕ 可以添加任务，自行决定后续任务。
  • V3 开始内置“专心挖煤模板 V2”预设；加载预设后，需设置好启动设置中的软件路径，即可尽量避免运行卡顿，并自动实现 MaaYuan 与模拟器重启。
  • 参考资料备注：战斗中的卡顿是其他原因造成，暂时无法解决；建议战斗成员为徐庶、孙尚香、周瑜。

往期版本 ​

  • 无后缀：可指定次数，可选刷三个层级（入云梦、龙虎一、龙虎二），版本 v0.9.0，次数上限 9999。
  • V2：默认无限次数，有自定义延迟，可选刷三个层级（入云梦、龙虎一、龙虎二），版本 v0.9.1。
  • V3：默认无限次数，有自定义延迟，增加识别精度，增加全部层级，版本 v0.9.2。

云梦巫乡挖煤自定义版 ​

新增 更换OCR模型开关：之前选择刷皮蛋路线时会在4层提前退出、或是更新版本后仍然遇到错误提示 已有巫竞正在进行中 的朋友可以尝试新增开关-更换OCR模型

除V4功能外，增加2个优先级选项和3个开关选择

  • 优先级选项：可选路径优先级（爬塔：正常战斗集符、刷煤：避开战斗、刷皮蛋–到8层重开、刷皮蛋-到36层重开、镜境三特供版、镜境四特供版）、降神符优先级（盾+持续伤害、盾+普攻、低层速刷、集符–百隶为盾、集符–执摄万灵、集符–烈火焚金、集符–令斩魂厄）

  • 开关选择：23层后无雷击木buff自动重开、云梦巫乡-方士小摊进行购物、云梦巫乡-战斗失败后重开巫竞

  • 刷载道岩洞，需要把编队1改为挂机队伍，爬65层/集符建议配合无雷击木buff自动重开+不进行购物+战斗失败不重开

  • 刷替天山窟，需要事先选过一次人+进去配过队

  • 刷皮蛋，8层重开版避开战斗，35层版正常发育，建议配合战斗失败后重开巫竞

  • 所有降神符优先级最高的都包括保证爬塔成功率的核心符文（不烬等）

东海海水浴场 ​

版本：补丁发布

  • 需要先将补丁打好（补丁在频道-作业分享区）

  • 在任务列表找到扫荡任务

  • 按照说明提前加好时辰并进入浴场

  • 需要一些时间进行连接

  • 时辰不足会自动停止任务并弹窗提醒

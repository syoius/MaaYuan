MaaYuan 是什么 ​

  • MaaYuan 基于 MaaFramework 的代号鸢/如鸢小助手。图像技术 + 模拟控制，解放双手！
  • MaaYuan 属于外置框架并非外挂，本质是精确识图连点器！
    • “加速”“全局扫荡”等功能属于外挂能力，MaaYuan 不会提供，也坚决抵制此类服务。
    • 本软件仅通过游戏提供的用户界面与游戏程序进行交互，不会读取或修改游戏的文件或代码。
  • MaaYuan 是免费提供下载使用，禁止以代下载盈利！
  • Windows 端图形界面基于 MFAWPF。

MaaYuan 能做什么 ​

🌿 日常一条龙 ​

  • 🚀 模拟器、游戏自启动（模拟器自启需设置模拟器路径！）
  • 📜 鸢报四连-日常专用
  • 💰 领月卡福利
  • 🍚 领取每日进膳体力
  • 🏯 据点日常（✔ 派遣 ✔ 据点情报 ✔ 据点商人、黑市购物）
  • 🔮 观星（✔ 观一次 ✔ 一键观星（需月卡）✔ 六步观星法 ✔ 无月卡连续观星60次）
  • 🏮 历练（✔ 自定义－｛关卡 + 等级 + 次数｝）
  • 🗡 白鹄行动 （✔每日扫荡 +领奖）
  • 🗡 地宫限定（✔ 每日扫荡 ✔ 雀部解密）
  • 🔨 心纸营建（✔适配当期家具活动 ✔史君小铺购物）
  • 🔶 其他日常（✔ 每日分享 ✔ 每日密探送礼 ✔ 相见互动 ✔ 家具互动✔ 首位密探升级 ✔ 领取密探奖励（全部领取））

⏳ 其他护肝功能 ​

  • 🔄 刷 6-24 / 7-15
    • 随时随地一键开刷，可在日常结束后自动进入，刷光剩余体力
    • 可选刷到体力耗尽（不会消耗白金币回体力）或 指定循环次数
  • 🔄【宇宙匣】三千世界
    • 不耗体力刷共同出战类成就
  • 🔄 自动刷洞窟
    • 支持 游戏内置自动战斗 及 抄作业 自动刷满洞窟 30 层
  • 🔥 自动走历险（首通/手动刷佛脚用，非自动派遣）
  • 🔥 【测试版】自动抄作业
  • 🔄 鸢报四合一 轮流做激活的鸢报事件，不浪费时间。会自动跳过鸟食数量不足的事件。 为了循环检查，决策事件和没有建材箱的物资支援会强制做掉，如不想“浪费”鸡炙，请使用单独的 🔄待办公务任务。

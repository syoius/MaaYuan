# 诸葛亮智能圈 v2.4.1

`DragonSmartAction` 读取同一张游戏截图里的龙脉、龙气和技能能量，连续两帧确认后，只将当前作业节点转向调用者提供的分支。识别与重试阶段不点击、不滑动。吕布的切换形态操作与本模块无关。

默认规则：龙脉外优先按四格技能能量选择技能或普攻；龙脉内 0 龙气下拉、1 龙气普攻、至少 2 龙气下拉。明确的固定动作不经过本模块。攻略可以重映射分支，例如曹丕第 6 回合将龙脉内两种分支都映射为普攻；此时龙气读数不影响选择。

参数示例（对象形式推荐，兼容最多三层旧字符串编码）：

```json
{
  "node": "回合8行动1",
  "position": 1,
  "branches": {
    "normal": "回合8行动1-普攻",
    "ultimate": "回合8行动1-技能",
    "defense": "回合8行动1-下拉"
  }
}
```

分支节点必须存在，并由作业负责动作、后续流程及失败停止。模块不会创建物理操作。`回合N行动` 格式的入口额外要求实际回合等于 N；其他入口也必须识别出有效战斗回合。回合未确认、状态模糊或背景仍变化时最多采样六次，不能确认则失败。兼容数字后一个分隔符，例如 `9/`；限回合关卡显示 `当前/上限`，例如 `1/10` 取当前回合 1、`10/10` 取 10。要求 1≤当前≤上限，不合并两边数字，也不将误读的 `1` 猜成 `7`。

v2.4.1 修复：2026-11-02 观察测试截图确认 `回合1/10` 是合法显示，OCR 结果正确，原智能圈解析器错误拒绝了该格式。本次只修复智能圈的文本解析，未修改通用 OCR 模型或范围。35 项离线测试通过，覆盖全部 1/10～10/10、非法上限和回合错位。

## 测试作业与生成技能

`诸葛亮全程智能圈-10回合测试-v2.4.json` 是用户实测的完整作业，文件名保留 v2.4；实际模块已是 v2.4.1，兼容当前/上限回合格式。复制到客户端 `resource/copilot-cache/` 后刷新并激活，手动进入第 1 回合，在“自动抄作业V3”开启“战斗中开始抄作业”。每回合先由 1 号位执行圈，其余四人依次普攻，最多 10 回合；动作不是固定的技能/防御序列。

生成技能位于 `.agents/skills/maayuan-copilot-builder/`，含编译器、坐标档位、IR schema、参考说明、示例与单元测试。默认导出只写缓存，保留当前激活作业。

```text
python tools/copilot/dragon_smart/build_test_job.py
python tools/copilot/dragon_smart/build_test_job.py --client <客户端根目录>
```

不加 `--client` 时使用仓库源码资源，在本目录生成作业；加参数时校验指定客户端资源并仅写缓存。生成过程中无游戏输入。部署运行模块时需包含两个 Python 文件、注册导入、JSON 配置和配置引用的七个模板；已有客户端只导入作业不能自动安装新模块。更新前停止客户端并备份。
